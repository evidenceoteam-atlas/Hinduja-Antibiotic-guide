# Seed Data

The application ships no active static treatment recommendation.

`rules/hinduja_protocols.json` is a retirement marker; the contradictory weighted evaluator returns HTTP 410. Clinical rows come from source assets, start as `pending_review`, and remain invisible to current doctor-facing views until an entire non-expired dataset release passes clinical activation gates.

The bundled 2025 release is intentionally expired. It is suitable for parser, migration, and UI failure-state testing only—not doctor-facing protocol use.
